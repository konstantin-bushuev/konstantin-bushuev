- знакомиться с новыми продуктами, проектами, технологиями

## 🎓 Профессиональное развитие

Прошёл интенсивный курс Яндекс.Практикума Full-Stack QA Engineer, где изучил теоретическую базу по тестированию и автоматизации, а также выполнил более 10 проектов по тестированию веб- и мобильных приложений, пользовательского интерфейса, API.

Продолжаю углублять свои знания в области тестирования и автоматизации, делаю пет-проекты для применения теории на практике, слежу за тенденциями и новостями тестирования и IT, планирую и дальше развиваться в области автоматизации.

Сейчас сотрудничаю с командой, создающей мультиплатформенное приложение. Разрабатываю тестовый фреймворк для автоматизации api, web и мобильного тестирования; преимущественно занимаюсь автоматизацией тестирования api и android-приложения.
